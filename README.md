# 💇 Kuaför Otomasyonu

Kuaför Otomasyonu, kuaför salonlarında müşteri, hizmet ve işlem kayıtlarının yönetilmesini kolaylaştırmak amacıyla geliştirilmiş bir Windows Forms uygulamasıdır.

Bu proje C# ve .NET Framework kullanılarak geliştirilmiştir ve salon içerisindeki günlük işlemlerin daha düzenli takip edilmesini sağlar.

## 🚀 Özellikler

- Müşteri kayıt işlemleri
- Saç boya kayıt yönetimi
- Kayıt güncelleme işlemleri
- Kayıt silme işlemleri
- Hizmet geçmişi takibi
- Windows Forms tabanlı kullanıcı arayüzü
- Veri yönetimi ve raporlama altyapısı

## 🛠 Kullanılan Teknolojiler

- C#
- Windows Forms
- .NET Framework
- Visual Studio

## 📋 Modüller

### Boya Kayıt
Müşterilere uygulanan boya işlemlerinin sisteme kaydedilmesini sağlar.

### Boya Güncelleme
Kayıtlı boya işlemlerinin düzenlenmesini sağlar.

### Boya Silme
İstenmeyen veya hatalı kayıtların sistemden kaldırılmasını sağlar.

### Kuaför Paneli
Uygulamanın ana yönetim ekranıdır.

## ⚙️ Kurulum

1. Depoyu klonlayın:

```bash
git clone https://github.com/ebubekirbastama/Kuafor-Otomasyonu.git
```

2. Visual Studio ile açın.

3. `Kuafor.sln` dosyasını çalıştırın.

4. Gerekli veritabanı bağlantı ayarlarını kontrol edin.

5. Projeyi derleyip çalıştırın.

## ▶️ Kullanım

1. Programı başlatın.
2. Ana panel üzerinden ilgili modülü seçin.
3. Müşteri veya hizmet kayıtlarını ekleyin.
4. Güncelleme ve silme işlemlerini ilgili ekranlardan yönetin.

## 🎯 Amaç

Bu proje, kuaför salonlarında gerçekleştirilen işlemlerin dijital ortamda takip edilmesini sağlayarak:

- Zaman tasarrufu sağlamak,
- Müşteri kayıtlarını düzenli tutmak,
- Hizmet geçmişini saklamak,

amacıyla geliştirilmiştir.
